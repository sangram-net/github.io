# Sangram Ganguly — Personal Website

A clean, minimal static portfolio for GitHub Pages or any static host.

## Files
- `index.html` — site structure and content
- `style.css` — responsive styling
- `script.js` — tiny year update
- `favicon.svg` — simple favicon

## Deploy on GitHub Pages
1. Create a repository (or use `<username>.github.io`).
2. Upload these files to the repository root.
3. Go to **Settings → Pages**.
4. Select **Deploy from a branch**, choose `main` and `/ (root)`.
5. Save.

The site contains direct links to the four GitHub projects and the supplied verification pages. The Credly profile link points to the current public profile linked from the GitHub account.
