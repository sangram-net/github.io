# Sangram Ganguly Portfolio

A responsive, multi-page personal portfolio built with plain HTML, CSS, and JavaScript.

## Pages
- `index.html` — home and featured projects
- `projects.html` — project catalogue with category filters and live search
- `certifications.html` — credentials and verification links
- `about.html` — profile and social links

## Run locally
Open `index.html` in your browser, or from this folder run:
```bash
python3 -m http.server 8000
```
Then visit http://localhost:8000.

## Deploy free
Upload the folder contents to a GitHub repository and enable GitHub Pages, or deploy the folder with Netlify or Cloudflare Pages.

The site uses Google Fonts when online, with system fallbacks. Theme selection is stored locally in the browser.
