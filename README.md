# Sangram Ganguly — Multi-page portfolio

A static, responsive portfolio with a warm editorial visual identity: paper background, ink typography, cobalt blue, and orange accents.

## Pages
- `index.html` — home
- `about.html` — background, experience, education, skills
- `projects.html` — four GitHub projects
- `credentials.html` — selected certificate badges
- `contact.html` — email and social links

## Run locally
Open `index.html` in a browser, or run a static server from this folder:
`python3 -m http.server 8000`

## Deploy
Upload the contents of this folder to GitHub Pages or any static hosting provider.
